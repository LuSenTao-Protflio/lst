# 全项目详情页编辑式改版设计规范

## 目标

将目前仍使用通用标题、占位叙事卡和三列图片网格的五个项目详情页，统一升级为面向面试官阅读的编辑式项目档案。保持整站一致的阅读逻辑，同时让不同图片数量形成不同节奏。

涉及项目：

- PROJECT 01 / 项目 01：WHELK 弧锂实验室
- PROJECT 03 / 项目 03：阿尔兹海默症·记忆的回流
- PROJECT 05 / 项目 05：FRIDAY 帆书年会视觉
- PROJECT 06 / 项目 06：有请讲书人
- PROJECT 07 / 项目 07：综合实践

WOOF-WOOF 和 MetaKeys 继续使用已经完成的专用详情组件。

## 统一框架

### 首屏项目档案

- 使用约 68/32 的双栏结构。
- 左侧展示项目 hero，保持原始 16:9 比例，不裁切。
- 右侧展示双语项目编号、项目标签、标题、中英文副标题、项目简介、项目类型、个人职责和项目年份。
- 桌面端右侧信息使用 sticky；800px 以下改为单列且信息位于 hero 之前。

### 内容叙事

- 移除原来的五张空白叙事占位卡。
- 每个项目补充三段真实内容：项目背景、设计策略、视觉落地。
- 不虚构上线数据、客户反馈、获奖结果或个人未完成的职责。
- 文字保持短段落，图片仍是页面主角。

### 图片节奏

所有现有素材均为 2880×1620，按自然比例展示：

- 8 张图片项目：hero + 全宽图 + 双列图 + 一大一小组合 + 双列图 + 全宽收尾。
- 7 张图片项目：hero + 全宽图 + 双列图 + 一大一小组合 + 双列收尾。
- 5 张图片项目：hero + 全宽图 + 双列图 + 全宽收尾。
- 4 张图片项目：hero + 全宽图 + 双列图。

hero 与内容图片允许重复使用现有数据中的第一张，但专用组件应避免在视觉叙事开头紧接着重复同一张图；正文从下一张素材开始编排。

## 项目内容方向

### WHELK

- 项目背景：古着品牌完整视觉系统。
- 设计策略：将潮汐磨损、铜器氧化与时间痕迹转译为品牌语言。
- 视觉落地：Logo、Pop Shop、包装与服装系列延展。
- 元信息：Brand Identity / Packaging / Fashion；品牌概念、视觉识别、包装与应用；2024–2025。

### 记忆的回流

- 项目背景：围绕阿尔兹海默症感知与记忆展开的叙事出版物。
- 设计策略：通过记忆锚点、透明、叠化和碎片化构建阅读体验。
- 视觉落地：主题海报、邮折系统与叙事物件。
- 元信息：Publication / Visual Narrative；研究整理、编辑设计、视觉系统；2024。

### FRIDAY 年会视觉

- 项目背景：帆书深圳书友年会全链路视觉。
- 设计策略：围绕“缘起·热爱”统一舞台、传播与现场识别。
- 视觉落地：KV、邀请函、打卡墙、导视与现场物料。
- 元信息：Event Design / Key Visual / Spatial Graphics；主视觉、物料延展、落地执行；2025–2026。

### 有请讲书人

- 项目背景：深圳读书月讲书人阅读分享活动。
- 设计策略：以统一视觉语言连接线上宣发和现场触点。
- 视觉落地：主海报、证件、邀请函、现场导视与延展物料。
- 元信息：Event Design / Key Visual / Branding；主视觉、规范建立、物料延展；2025。

### 综合实践

- 项目背景：演讲视觉、书店运营物料与南头古城 AR 导航实践。
- 设计策略：根据不同传播场景建立清晰的信息层级。
- 视觉落地：主题海报、书单展架、活动物料与移动界面。
- 元信息：Visual Design / UI Design / AR；视觉设计、版式设计、UI界面；2024–2025。

## 页面结尾

- 每页左侧提供“返回全部项目”。
- 右侧按照项目顺序链接到下一个项目：01→02、03→04、05→06、06→07、07→01。
- 使用项目标题作为下一项目文本，不使用图片推荐卡。

## 实现结构

- 创建共享 `EditorialProjectDetail` 组件，服务上述五个项目。
- 项目专属文案存放在现有 i18n 项目对象的 `detail` 字段。
- 图片组合根据 `project.images.length` 和索引序列渲染，不增加第三方瀑布流或布局依赖。
- 删除通用详情组件中不再使用的 narrative 占位逻辑，但保留 not-found 处理。

## 响应式与验证

- 800px 以下，双栏和所有图片组合改为单列，sticky 失效。
- 图片宽度 100%、高度 auto、object-fit contain。
- 验证五个页面均无 `.narrative-card` 和旧 `.detail-grid`。
- 验证全部素材加载且自然比例与渲染比例一致。
- 验证七个项目均显示双语项目编号，所有下一项目链接正确。
- 验证生产构建通过且页面无横向溢出。
