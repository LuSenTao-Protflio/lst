# 天安云谷（日常）读书节 Illustrator 长页设计规格

日期：2026-08-01

## 目标

以与 FRIDAY 年会相同的“大厂策略型案例”方法，为天安云谷（日常）读书节创建一份独立、可编辑的 Adobe Illustrator 作品集长页，并同步提供 HTML 排版参考。案例需要从项目背景、活动机制和设计策略出发，证明设计者能够把一个持续 42 天的社区文化活动转化为清晰、活跃且可持续延展的传播系统。

本轮不接入 React 网站，也不覆盖现有作品集 PDF 和源素材。

## 已确认事实

- 项目名称：天安云谷（日常）读书节 / Daily Reading Festival
- 项目定位：深圳首个聚焦社区生活的读书文化节
- 活动时间：2025.06.20–2025.07.31
- 活动周期：42 天
- 活动机制：以书换咖、以书换书、以书换蔬、以书换植
- 主张：阅读即日常 / Reading Is Daily Life
- 合作方和活动信息以现有海报为准
- 个人职责：主要负责视觉设计与落地执行

不增加未经素材证明的参与人数、兑换数量、传播数据或商业结果。

## 设计方向

在三个可行方向中选择策略型完整案例：

1. **策略型完整案例（采用）**：背景、机制、概念、系统和应用依次展开，招聘价值最高；
2. 视觉画册型：以海报大图为主，但不足以解释 42 天活动机制；
3. 精简传播型：只展示主视觉与四张分主题海报，页面更短但无法证明信息系统能力。

核心叙事为：**把阅读从一次文化活动，变成每天都能参与的社区交换。**

主视觉中的打开书本与左右双手共同构成“交换”的动作。书页既是阅读媒介，也像被打开的社区入口；高饱和黄色建立公共活动的可见度，粉、蓝、绿等颜色对应不同交换主题，让复杂活动信息保持统一又便于区分。

## 画板结构

### 01 封面 / Cover

- 尺寸：1440 × 810 px
- 使用 `主视觉.png` 满版裁切
- 叠加项目编号、项目名称、英文名和职责
- 主标题：82–104 px
- 安全边距：48 px

### 02 项目背景 / Context

- 暖白底色，左右双栏
- 左栏约 400 px：结论型标题
- 右栏约 650 px：项目背景、活动周期、项目类型、职责
- 重点信息：42 天、2025.06.20–07.31、四阶段交换机制
- 引导正文：21–23 px；正文：15 px

背景文案：天安云谷联合帆书深圳运营中心，将阅读活动放入社区日常生活，以持续 42 天的内容和交换机制连接园区居民、书店与社区伙伴。项目需要把跨月日程、不同参与方式和多方活动信息组织成易理解的传播系统。

### 03 活动机制 / Mechanism

- 核心标题：一本书，换一份日常惊喜
- 展示四阶段：咖、书、蔬、植
- 每阶段明确日期与对应色彩
- 使用 `云谷制作_画板 1 副本 8.jpg` 与 `优化版/11.png` 中可证明的内容
- 四卡网格，卡片间距 22–24 px

### 04 核心洞察与概念 / Insight & Concept

- 黄色满版转场，局部使用白色信息框
- 核心句：把阅读从一次文化活动，变成每天都能参与的社区交换
- 主图形：打开的书本 + 两侧手势
- 说明 `READING IS DAILY LIFE` 如何嵌入书页结构
- 核心句：72–82 px；概念正文：16 px

### 05 视觉系统 / Visual System

三部分并列：

1. **开放书页**：既是阅读符号，也是社区入口和交换平台；
2. **行动手势**：强调递出、接收和参与，弱化静态阅读的距离感；
3. **主题色彩**：黄色作为公共底色，粉、蓝、绿区分活动内容。

补充说明白底黑框信息标签如何像社区公告和活动贴纸一样灵活组合。

### 06 四周主题 / Four Exchanges

- 使用 `优化版/11.png` 作为系统总览
- 按咖、书、蔬、植拆成四个等宽模块
- 每个模块包含日期、英文副标题、主题图形和简短说明
- 图片区域优先保持原比例，不拉伸

### 07 日历与信息架构 / Calendar

- 使用 `云谷制作_画板 1 副本 12.jpg`
- 将月历作为主要视觉证明，展示 42 天活动信息如何被组织
- 图注说明日期、活动类型、地点和二维码入口的层级关系
- 保持日历文字可辨识，避免过度裁切

### 08 主视觉与尺寸适配 / Key Visual Adaptation

- 使用 `云谷制作-09.jpg`、`云谷制作_画板 1 副本 10.jpg` 和 `主视觉.png`
- 展示横版、竖版和独立图形三种状态
- 说明相同识别单元如何适配不同媒介比例

### 09 内容传播 / Content Communication

- 使用 `云谷制作_画板 1 副本 11.jpg`
- 展示六位作者与活动内容的系列传播
- 图注说明人物信息、活动标题和合作方信息的层级处理
- 不宣称未经证明的到场结果

### 10 总结与 AI 排版指南 / Summary & Guide

- 总结设计如何连接社区生活、阅读和交换机制
- 列出画板、边距、字号、行距、间距和正文行宽
- 保留可隐藏的尺寸标注层，方便用户在 Illustrator 中继续调整

## 网格与排版

- 画板宽度：1440 px
- 文字安全边距：72 px
- 大图安全边距：48 px
- 正文最大行宽：600–650 px
- 主标题：82–104 px
- 章节标题：48–58 px
- 引导正文：21–23 px
- 正文：15 px
- 图注：12–13 px
- 常用间距：24 / 48 / 72 / 120 px
- 中文字体优先使用苹方或思源黑体，不转曲

## 图层结构

1. `00-GUIDES`
2. `01-TYPE`
3. `02-GRAPHICS`
4. `03-IMAGES`
5. `04-ANNOTATIONS`

每个章节内对象使用 `B01-` 至 `B10-` 前缀命名。图片使用置入和裁切蒙版，避免拉伸。标注独立放置，便于用户一次性隐藏。

## 验收标准

- AI 文件可正常打开并包含 10 个命名画板和 5 个命名图层；
- HTML 参考与 AI 的章节、尺寸和素材顺序一致；
- 至少使用主视觉、四主题机制、日历、竖版 KV 和作者内容五类素材；
- 42 天、四阶段、日期和个人职责准确；
- 文字无明显溢出、缺字或重叠；
- 图片不拉伸，重要文字不被错误裁切；
- 原素材和已有 PDF 不被覆盖；
- 不出现虚构数据和未经证明的活动成效。
