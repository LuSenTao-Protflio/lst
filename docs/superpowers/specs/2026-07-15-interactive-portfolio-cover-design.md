# 交互式作品集封面设计规范

## 目标

在现有首页首屏之前新增一张永久保留的全屏交互封面。封面承担初始动画、个人作品集识别、项目快速导航和进入现有首页四项功能，不作为自动消失的加载页。

## 页面结构

- 封面位于 Home 最前方，使用 `min-height:100svh`。
- 现有深灰 Graphic Design Portfolio 首屏紧接在封面下方，并增加稳定锚点 `#portfolio-home`。
- 用户可以向上滚动重新回到封面。

## 视觉方向

- 背景：暖白 `#FFFDF5`。
- 主文字：中性深灰 `#3A3A3A`。
- 强调：荧光黄 `#E6FF1A`，只用于荧光笔标记、编号状态和进入按钮。
- 中文标题使用超粗无衬线，并在独立包装层上横向压缩至约 86%，形成窄体海报感。
- 英文、项目类型和编辑信息使用现有 Manrope。

## 标题内容

- 主标题第一行：`卢森涛`
- 主标题第二行：`个人作品集网站`
- 英文副标题：`LUSEN TAO — PERSONAL PORTFOLIO`
- 编辑信息：`VISUAL COMMUNICATION / SHENZHEN / 2026`
- “个人作品集”使用不规则荧光笔标记，但避免完整矩形色块。

中英文切换时，中文模式保留上述双语标题；英文模式使用 `LUSEN TAO` 与 `PERSONAL PORTFOLIO WEBSITE`，保留一行中文署名作为辅助信息。

## 项目目录

- 右侧纵向列出全部七个项目，数据直接读取现有 `projects` 和 i18n。
- 每行显示：双位项目编号、项目标题、第一项项目类型。
- 行链接直接进入 `/project/<id>`。
- 悬停一行时，当前行保持深灰，其他行变为低透明度。
- 当前文字做一次克制的向上翻动。
- 对应 `project.hero` 以横版预览图跟随鼠标出现，尺寸约 360×230px，保持图片比例并使用 `object-fit:cover`。
- 预览图使用 spring 追随，不遮挡点击，离开目录时淡出。
- 移动端取消鼠标跟随预览，目录保持可点击并改为封面下半部分。

## 初始动画

首次挂载 Home 时播放：

1. 顶部编辑信息淡入。
2. “卢森涛”从裁切容器向上揭示。
3. 第二行标题延迟揭示，荧光笔标记横向展开。
4. 英文副标题淡入。
5. 七个项目行依次上移淡入。
6. 进入按钮最后出现。

动画总时长控制在约 1.5 秒，不阻塞项目链接点击。

## 进入现有首页

- 封面底部提供玻璃按钮：`↓ 进入作品集 / Enter Portfolio`。
- 点击按钮平滑滚动到 `#portfolio-home`。
- 当封面处于顶部且用户第一次明显向下滚动滚轮时，拦截该次滚动并平滑滚动到 `#portfolio-home`。
- 只在封面顶部范围内触发一次；进入现有首页后恢复正常滚动，避免滚轮劫持。
- 系统开启减少动态效果时不拦截滚轮，按钮使用即时滚动。

## 组件边界

- 创建 `InteractiveCover.jsx`：封面布局、项目目录与进入交互。
- 创建 `HoverProjectReveal.jsx`：目录悬停、图片跟随与文字状态。
- Home 只负责挂载封面并为原 hero 添加锚点。
- 复用现有 Framer Motion，不新增依赖。

## 与现有功能协同

- 全局自定义鼠标和点击圆环在封面继续生效。
- 首页右下角“返回顶部”按钮仍以 WHELK 项目为显示阈值，不因新增封面提前出现。
- 项目页“全部项目”按钮返回 `/#directory`，不会进入封面。
- 顶部玻璃导航仍属于现有深灰首页，不显示在封面内。

## 验证

- 首页首次进入显示完整封面和七个项目链接。
- 七个项目悬停时显示正确 hero，离开后隐藏。
- 每个项目链接进入正确详情页并回到页面顶部。
- 向下滚轮和进入按钮均能到达 `#portfolio-home`。
- 用户可向上滚回封面。
- 移动端无悬停浮图、无横向溢出，项目链接可点击。
- 生产构建通过。
