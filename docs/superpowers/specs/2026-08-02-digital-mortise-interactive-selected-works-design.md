# 「数字榫卯，重构木艺基因」Selected Works 独立交互案例设计规格

日期：2026-08-02

## 目标

将 Canva 中 18 页的木雕传统工艺科普交互项目整理为 Selected Works 内部的独立完整案例。案例使用 6 个 Illustrator 画板，呈现从传统文化研究、交互结构、UI 视觉到 Arduino 与实体神龛原型的完整设计链路。

项目仍归入“其他视觉实践 / Selected Works”，不提升为作品集主目录中的第九个项目；但在 Selected Works 内部拥有独立标题、完整过程与项目总结，不按普通杂项缩减为 2-3 页。

## 已确认来源

- Canva 设计：`https://www.canva.cn/design/DAGiFr2PUWI/pleeE5zyfrpbmH-UuMYHNg/edit`；
- Canva 文件标题：`大神龛`；
- 原设计共 18 页；
- 原设计可见内容包含项目选题、背景分析、用户与任务分析、设计方案、低保真结构、Arduino 程序、桌面端 UI、交互流程、实体神龛、灯光效果和最终原型展示。

所有事实、流程与图片以 Canva 原设计中的可见内容为准。实施阶段可以导出代表页作为素材，但不得代购、绕过付费限制或使用带水印页面。

## 项目定位

项目名称：**数字榫卯，重构木艺基因**

副标题：**关于木雕传统工艺的科普向交互设计**

项目类型：传统文化科普 / 桌面端交互 UI / Arduino 原型 / 实体交互装置

Selected Works 标签：**Interactive Installation / UI Design / Arduino Prototype**

个人职责：**负责项目策划、资料研究、信息架构、交互流程、UI 视觉、Arduino 程序与实体原型设计。**

核心叙事：**把木雕知识从静态观看转化为可操作、可反馈、可感知的数字体验，让传统木艺通过界面、灯光与实体装置重新被理解。**

不虚构访谈人数、用户测试样本、文化传播效果、展览数据或技术性能指标。

## 设计问题

传统木雕工艺的知识结构复杂，常见展示方式以文字、图片和实物陈列为主，观众容易停留在表层观看。项目需要同时解决三个问题：

1. 如何把工艺知识拆成易理解的内容层级；
2. 如何用交互操作建立“观看—探索—反馈”的学习过程；
3. 如何让数字界面与木质神龛装置形成统一体验，而不是彼此分离。

## 交互逻辑

案例以“数字榫卯”为体验隐喻。用户从界面选择木雕主题或知识节点，浏览工艺信息并触发对应状态；Arduino 与实体装置负责将数字操作转化为灯光或装置反馈，形成完整闭环：

**选择内容 → 浏览知识 → 触发交互 → 装置反馈 → 建立理解**

实施阶段只陈述原方案可证明的输入、反馈和界面关系，不补写未展示的传感器类型、通信协议或测试结果。

## 画板结构

### 01 项目概览

- 画板：1440 × 900 px；
- 使用原封面和最终装置作为主要视觉；
- 交代项目背景、目标、类型、职责和核心叙事；
- 首屏标题强调“让传统木艺从被观看，变成可操作的知识体验”。

### 02 文化背景与设计问题

- 展示木雕传统工艺、知识内容与现有传播方式的研究素材；
- 提炼“内容复杂、观看被动、数字与实体割裂”三个问题；
- 使用“传统知识 → 信息拆解 → 交互转译”的推导关系；
- 不使用未经证明的调研人数或统计数据。

### 03 信息架构与交互流程

- 展示用户任务、内容层级、低保真界面与主要流程；
- 将流程压缩为“进入主题—选择内容—查看细节—触发反馈—继续探索”；
- 用独立流程线与节点重新组织原方案，不篡改原图信息；
- 重点证明从研究到交互结构的推导能力。

### 04 UI 视觉系统

- 完整展示桌面端主界面、内容页、弹窗或关键状态；
- 说明深木色、暖金、米白与炭黑如何对应木雕、灯光和数字界面；
- 拆解导航、内容卡片、操作区、状态反馈和信息层级；
- 保留原 UI 的暗色沉浸感，并提高作品集中的页面可读性。

### 05 数字界面与实体装置联动

- 展示 Arduino 程序、交互逻辑、装置结构与输入输出关系；
- 使用“UI 操作 → 程序判断 → 灯光/装置反馈”的三段式图解；
- Arduino 代码作为技术能力证据，不把代码截图当作主要视觉；
- 强调数字界面与实体神龛共享同一套内容和反馈逻辑。

### 06 最终原型与项目总结

- 完整展示神龛实体、灯光效果、制作过程和使用场景；
- 用大图建立结束页的完成度，辅以材料、结构和触点说明；
- 总结项目如何把传统文化内容转译为界面、程序和实体体验；
- 页脚继续标记 `SELECTED WORKS / INTERACTIVE INSTALLATION`，保持杂项分类关系。

## 视觉方向

- 主色：深木棕、炭黑、米白、暖金；
- 强调色：从原界面与灯光中提取的琥珀金，不额外引入高饱和科技蓝；
- 使用榫卯结构线、木雕纹样、模块节点、细网格、扫描光和状态光点作为小元素；
- 画板采用非对称编辑网格，研究页克制、UI 页高对比、原型页大图收束；
- 原始页面与照片全部使用 `contain`，确保界面、代码、装置和文字信息完整；
- 装饰元素不得遮挡原设计内容；
- 保持与全站 Selected Works 的命名和页脚系统一致，同时给予该项目更完整的阅读篇幅。
