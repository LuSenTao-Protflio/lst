## 项目定位

项目名称：**SmallRig 焦点计划**

项目类型：品牌活动策划 / 视觉识别 / 活动 IP / 传播周边

个人职责：**负责活动概念、视觉系统、活动 IP、内容传播与周边应用设计。**

核心叙事：**以“在灰调世界增加一抹红色”为传播概念，把 SmallRig 的摄影器材基因转化为可识别的活动视觉、摄影内容和参与者周边。**

不虚构活动执行结果、参与人数、传播数据、商业转化或用户反馈。

## 设计逻辑

### 背景与挑战

摄影器材品牌需要在产品功能之外建立更具参与感的品牌内容。方案以面向摄影创作者的主题活动为载体，需要同时解决活动概念识别、品牌一致性、内容产出与周边延展。

### 核心概念

“寻找生活的焦点 / Focus Planning”将摄影中的焦点转化为活动主题；“在灰调世界增加一抹红色”则把品牌红作为视觉线索。黑白摄影承载生活观察，红色负责定位主体、建立节奏并强化品牌记忆。

### 视觉系统

- 黑、白、灰构成摄影基底；
- 品牌红 `#D32228` 用于焦点、取景标记与活动识别；
- 活动标志提取 SmallRig 三脚架与品牌色；
- 活动 IP 结合三脚架可伸缩的结构特征，形成高矮不同的角色家族；
- 取景框、焦点坐标、胶片编号和红色定位点作为作品集小元素。

### 落地路径

1. 以黑白摄影加红色主体建立统一内容风格；
2. 通过活动 IP 增加品牌亲和力与活动识别；
3. 将视觉系统延展到钥匙扣、明信片、红色定位器、摄影墙和互动装置；
4. 让内容、奖品与现场触点共享同一套视觉语言。

## 画板结构

### 01 项目概览与核心策略

- 画板：1440 × 900 px；
- 使用原 PDF 第 1 页作为主视觉，完整展示；
- 补充项目背景、挑战、职责与一句话策略；
- 使用取景框四角、对焦十字和红色定位点建立摄影语境。

### 02 视觉系统与活动 IP

- 画板：1440 × 900 px；
- 完整展示原 PDF 第 2 页（活动标志）与第 4 页（色彩系统）；
- 用独立可编辑信息卡说明“品牌基因 → 活动标志 → 角色 IP → 红色焦点”；
- IP 说明以文字和简化矢量角色呼应，不使用包含付费波浪装饰的 PDF 第 3 页。

### 03 内容传播与周边落地

- 画板：1440 × 900 px；
- 完整展示原 PDF 第 6、7、10、11、12 页中的代表画面，使用错位网格但不裁切；
- 以“摄影内容 / 主打周边 / IP 衍生 / 参与触点”四类标签组织信息；
- 结尾总结视觉从摄影内容延伸至参与者可带走的物件和活动空间。

## 视觉方向

- 黑色为主背景，暖白用于信息卡与留白，品牌红 `#D32228` 为高强度强调色；
- 使用非对称网格、错位大标题、细红线、编号、对焦十字和胶片边框；
- 所有源图使用 `contain`，不拉伸、不裁掉原页面信息；
- 装饰元素不得覆盖源设计中的标题、Logo、图像或正文；
- 保持 Selected Works 的短案例节奏，避免复制原方案的 29 页完整目录。
