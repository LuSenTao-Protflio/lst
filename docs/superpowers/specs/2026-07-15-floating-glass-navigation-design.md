# 右下角玻璃导航按钮设计规范

## 目标

将现有项目页纯色圆形“全部项目”按钮升级为带文字的玻璃胶囊，并在首页进入第一个具体项目之后提供同款“返回顶部”按钮。

## 共享视觉

- 按钮采用横向胶囊，不再使用纯色圆球。
- 背景使用 `rgba(230,255,26,.38)`，与顶部导航一致。
- 使用 `backdrop-filter: blur(30px) saturate(145%)`。
- 加入半透明暖白描边、顶部高光、内阴影和深灰投影。
- 高度约 48px，桌面端使用图标与文字，移动端保留文字但缩小间距。
- 悬停时背景稍微增强、向上移动 2px；键盘 focus 有清晰轮廓。
- 固定在右下角，并考虑 safe-area。

## 项目详情页状态

- 内容为四格目录图标 + `全部项目`；英文模式显示 `All projects`。
- 所有项目详情页始终显示。
- 点击返回 `/#directory`。

## 首页状态

- 首页首屏、个人信息和 Projects 目录阶段不显示。
- 当用户滚动到第一个具体项目 `#whelk` 的起始位置后淡入。
- 内容为向上箭头 + `返回顶部`；英文模式显示 `Back to top`。
- 点击使用平滑滚动返回页面最顶部。
- 当滚动位置重新高于第一个具体项目时淡出并设为不可交互。

## 实现

- 创建共享 `FloatingGlassNav` 组件，根据 `useLocation().pathname` 判断首页或项目页。
- 首页使用滚动监听读取 `#whelk` 的 `offsetTop`，同时监听窗口尺寸变化以更新阈值。
- `ProjectChrome` 移除现有 `AllProjectsButton` 标记，只保留项目导航和共享页脚。
- `FloatingGlassNav` 在 `App.jsx` 路由范围内全局挂载一次。
- 使用现有 i18n 语言状态生成按钮文字，不新增重复翻译文件。

## 验证

- 首页进入第一个项目之前按钮隐藏，进入后显示，返回上方后隐藏。
- 点击返回顶部后滚动位置为 0。
- 七个项目详情页始终显示“全部项目”玻璃按钮。
- 点击后回到首页 Projects 目录。
- 按钮不遮挡项目导航、邮箱或自定义鼠标。
- 生产构建通过。
