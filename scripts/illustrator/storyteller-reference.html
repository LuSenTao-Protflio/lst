PROJECT 07 / EVENT VISUAL
01 / CONTEXT

阅读不只发生在书页里，也发生在一次被听见的讲述中。

“有请讲书人”是第 26 届深圳读书月中的阅读分享活动，以讲述与公共表达连接一本书、一个人的理解和更多听众。

视觉需要覆盖活动传播、评选沟通、总决赛、现场空间与线上邀请。设计既要保持公共文化活动的正式感，也要让参与者感到舞台是可接近、可加入的。

项目类型读书月活动视觉
项目时间2025
传播范围线上传播 / 现场空间
个人职责主要负责主视觉、视觉规范与物料延展

03 / INSIGHT & CONCEPT

让阅读从个人理解走向公共表达。

层叠结构从书页逐步转译为台阶、建筑与舞台：每一次阅读理解，都是向表达靠近的一层。麦克风确定“讲述”的动作，连续流线则像声音与路径，把分散触点连接成同一场活动。

READ → UNDERSTAND → SPEAK → SHARE
04 / VISUAL SYSTEM

一套识别语言，承载阅读、进步与讲述。

暖金与橙红建立公共文化活动的温度，蓝色为参与传播提供清晰对比。字体、层叠几何和流线共同维持正式识别。

01

上升的书页

层叠几何同时像书页、台阶和舞台，形成由阅读走向表达的路径。

02

持续的讲述

流动线条连接画面边界，转化声音、时间与活动动线。

03

温暖的公共色彩

#EED795 / #F1CA5F / #D58346；#6887BE 负责传播对比。

05 / ENGAGEMENT VISUAL

把“走上舞台”，变成一眼可感知的参与动作。

参与传播使用蓝黄三维阶梯、漂浮书本与麦克风。阶梯让“进步”变得具体，也把讲述舞台塑造成可以一步步靠近的空间。它与金色官方识别承担不同传播层级。

06 / LAYOUT RULES

固定识别层级，适配横版、竖版与不同信息密度。

Logo 区、标题区、主图形区与信息区保持稳定关系；尺寸变化时重新组织，而不是简单等比缩放。

07 / SPATIAL APPLICATION

从远距离识别，到近距离行动指引。

灯箱海报承担活动识别与时间信息，立式导视承接签到和现场行动。相同的金色层叠结构，在不同观看距离中调整主次与裁切。

完整物料关系 / 灯箱、导视与签到触点

局部放大 / 在空间距离中保留标题与日期识别

08 / EVENT & DIGITAL TOUCHPOINTS

视觉从现场空间，延续到身份与线上邀约。

舞台分享、集体留影、工作证和移动端邀请共同构成活动记忆。统一的色彩、标题结构和线性图形让触点保持连续。

现场 / 分享、舞台与共同留影

数字与身份 / 工作证、移动端邀请

09 / SUMMARY & AI BUILD GUIDE

把阅读、表达与公共分享，组织成一段连续体验。

项目以层叠书页和流动线条建立官方识别，再用三维阶梯强化参与传播。视觉从横竖版规范延展至空间导视、活动现场、证件与移动邀请。主要负责主视觉、视觉规范与物料延展。
