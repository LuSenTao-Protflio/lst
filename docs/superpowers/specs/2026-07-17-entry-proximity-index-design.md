# 入口页邻近项目索引设计

## 目标

将入口页中部的项目名称从单一 hover 放大，升级为具备距离衰减的项目索引：鼠标靠近任意一行时，该行与附近行依距离产生平滑的字号、亮度、刻度与横向位移变化。当前被指向的项目继续显示右侧主视觉预览，项目链接和进入详情页的行为不变。

同时移除顶部黄色玻璃任务栏和底部胶囊按钮，将两者改为与项目索引一致的纯文字网格排版；保留入口页现有橄榄绿磨砂玻璃和下方鼠标驱动光线。

## 页面构成

### 顶部文字网格

- 不使用背景、边框、圆角、玻璃容器或按钮底色。
- `WORK`、`INFO`、`CONTACT/联系我` 作为原有目标的纯文本按钮，落在项目最大宽度内的固定网格列上。
- 导航通过上下较大的空白、统一的小型字距和细小索引标记建立秩序；悬停时只提升不透明度和产生极小位移。
- 保留键盘 focus 环和既有 `/portfolio` 锚点目的地。

### 中部邻近项目索引

- 七个项目保持既有顺序与真实详情页链接。
- 每行增加两位项目编号和一条短刻度线，形成由左至右的「编号 / 标记 / 项目名称」结构。
- 在精细指针设备上，项目列表依据鼠标相对每行中心点的距离计算 `0–1` 效果值；效果以 requestAnimationFrame 平滑逼近：
  - 项目名称放大、提亮，并最多向右偏移约 24px。
  - 当前近距离项目的编号和刻度线使用酸性亮黄；邻近项目以较弱幅度响应。
  - 项目名称所对应的主视觉预览沿用现有右侧浮动卡片，只在距离最小的当前项目显示。
- 离开列表时，所有行平滑回到静态索引状态。
- 点击任意行仍进入该项目详情页；键盘 focus 使用当前项目的完整强调与预览状态。

### 底部文字入口

- 移除黄色胶囊按钮与阴影，仅保留「进入作品集 / ENTER PORTFOLIO」文字和 `↓↓` 双下箭头。
- 它以文本链接/按钮形式对齐至同一页面网格，并保留既有点击、向下滚动和淡出进入逻辑。
- 悬停只改变颜色与向下微移，避免与中部项目索引竞争。

## 组件边界

- `HoverProjectReveal` 吸收邻近距离计算与项目行渲染；继续是项目预览与详情链接的唯一入口。
- 项目行的动态值可通过 CSS custom property（例如 `--proximity`）写入真实 `Link`，避免在每次鼠标移动时触发 React 全量重渲染。
- `InteractiveCover` 只调整顶部/底部标记与可访问名称，不管理项目索引的鼠标循环。
- `styles.css` 负责网格、刻度、颜色、基于 `--proximity` 的变形和移动端降级；不引入新的依赖、图片或字体。

## 可访问性与降级

- 保留项目名称文字与链接语义，编号和刻度线均为装饰性元素。
- 键盘 focus 将对应行设为激活状态，并可显示已有预览；离开后正常清除。
- 对触摸设备和 `prefers-reduced-motion`：不启动 requestAnimationFrame 邻近循环，不显示依赖 hover 的预览，项目行保持清晰静态，仍可点击。
- 顶部文本导航和底部进入入口具有可见 focus 样式与足够点击区域。

## 验收

- 入口页没有顶部任务栏、玻璃容器或底部胶囊按钮。
- 顶部导航和底部进入入口使用纯文字、网格对齐和充足留白；底部显示双下箭头。
- 桌面端鼠标在项目列表移动时可见平滑的邻近响应；当前项目预览仍正确匹配。
- 各项目链接、顶部锚点、入口淡出转场、移动端布局与减少动态效果不回归。
