# WOOF-WOOF 项目详情页改版设计

## 目标

将 WOOF-WOOF 详情页从通用项目网格升级为适合面试阅读的编辑式项目档案。参考 Keita Takemura Studio 项目页的双栏比例、留白和连续图片叙事，但保留现有作品集的暖白、荧光黄与深灰视觉语言。

本轮只改 `/project/woof`，其他项目详情页保持原样，用于验证模板后再决定是否推广。

## 色彩调整

- 全站中性深灰由 `#2b2b2b` 提亮为 `#3a3a3a`。
- 暖白 `#fffdf5` 和荧光黄 `#e6ff1a` 保持不变。
- 荧光黄只用于标签、关键状态和少量强调，不作为大面积背景。

## 桌面端结构

### 顶部导航

沿用现有玻璃导航，不新增独立菜单。详情页提供清晰的返回作品入口。

### 首屏项目档案

采用约 68/32 的双栏布局：

- 左侧：WOOF-WOOF 主视觉大图，保持原始比例，不使用卡片、阴影或大圆角。
- 右侧：吸附式项目信息栏，包含项目编号、标题、中英文副标题、项目概述、标签、项目类型、个人职责和年份。
- 信息栏随首组视觉滚动，进入后续内容时保持可读，但不遮挡页脚。

### 内容叙事

取消当前空白的五张叙事占位卡，改为真实内容段落和视觉组合：

1. 项目背景与设计目标：大图配短说明。
2. 核心体验：两张手机界面并排，突出遛狗地图、路线与宠物友好地点。
3. 功能细节：使用非对称双栏，一张主界面配一张局部或辅助界面。
4. 视觉系统：连续展示角色、色彩和界面延展素材。
5. 项目总结：用简短陈述说明设计价值，不虚构上线数据或商业结果。

现有 6 张 WOOF-WOOF 图片全部保留，按叙事功能重新排序。图片采用自然比例与克制间距，不裁成统一卡片。

### 页面结尾

- 保留“返回全部项目”。
- 增加“下一个项目”文字入口，目标为现有项目顺序中的“阿尔兹海默症·记忆的回流”。
- 不增加复杂推荐卡片或联系表单。

## 移动端

- 双栏改为单列：项目信息先出现，主视觉随后。
- 信息栏取消 sticky，避免占用屏幕高度。
- 手机界面组合在窄屏上改为单列，不强制缩小到难以阅读。
- 页面左右边距沿用现有响应式变量，图片允许接近满宽。

## 动效

- 只使用轻微淡入和纵向位移，延续现有 Framer Motion。
- 不加入滚动劫持、复杂视差或图片缩放跟随。
- 尊重系统的 `prefers-reduced-motion` 设置。

## 实现边界

- 在现有 React、React Router、Framer Motion 与 CSS 体系内实现。
- 为 WOOF-WOOF 增加专用详情布局分支，通用详情组件继续服务其他项目。
- 不添加第三方依赖。
- 不修改项目图片文件，不虚构研究过程、上线结果或量化数据。

## 验证标准

- `/project/woof` 桌面端呈现大图左栏与信息右栏，且信息栏 sticky 行为正常。
- 六张现有图片均能加载，比例无变形。
- 其他详情页结构不受影响。
- 1280px 桌面宽度和约 390px 移动宽度下无横向溢出。
- 返回项目与下一个项目链接可正常使用。
- 生产构建通过。
