# 有请讲书人——读书月活动视觉 Illustrator 长页设计规格

日期：2026-08-01

## 目标

沿用 FRIDAY 年会与天安云谷读书节已经确认的“大厂策略型案例”方法，为“有请讲书人”建立一份独立、可编辑的 Adobe Illustrator 作品集长页，并同步提供 HTML 排版参考。案例不仅展示成品，还要让招聘方理解项目背景、活动传播链路、核心视觉概念、系统规范和真实落地。

本轮不接入 React 网站，不覆盖现有作品集 PDF、图片和源素材。

## 已确认事实

- 项目名称：有请讲书人 / GO! STORYTELLER!
- 项目属性：第 26 届深圳读书月阅读分享活动视觉
- 项目目的：连接阅读、表达与公共分享，支持活动传播、评选流程和现场呈现
- 活动链路：报名传播、评选沟通、总决赛、现场分享与留念
- 素材中可见的活动日期：2025.11.15 与总决赛 2025.11.29
- 个人职责：主要负责主视觉、视觉规范与物料延展
- 项目时间：2025

不增加未经素材证明的参与人数、传播数据、获奖结果、商业转化或用户评价。不同日期只作为现有物料事实展示，不擅自解释为未被证明的具体赛制阶段。

## 设计方向

可行方向有三种：

1. **策略型完整案例（采用）**：背景、传播挑战、洞察、双层视觉语言、规范和落地依次展开，最适合求职作品集；
2. 视觉画册型：以主视觉、海报和现场照片为主，更有冲击力，但无法证明系统思考；
3. 单一 KV 推导型：集中讲官方金色 KV，结构清晰，但会遗漏招募传播和多触点应用。

核心叙事为：**让阅读从个人理解走向公共表达。**

官方主视觉以书页般上升的层叠结构、流动线条和麦克风符号，把“阅读—理解—表达—分享”的过程转化为向舞台生长的视觉路径。暖金、橙红色建立深圳读书月正式而温暖的公共文化气质；招募与评选传播使用更具亲和力的蓝黄三维阶梯、漂浮书本和麦克风，让“走上讲述舞台”的参与动作更直观。两套表现不是两个割裂风格，而是同一活动在品牌识别层与参与传播层的分工。

## 画板结构

### 01 封面 / Cover

- 尺寸：1440 × 810 px
- 使用 `有请讲书人2025横版主kv.png` 完整呈现官方主视觉
- 不重复叠加素材中已有的大标题和日期，只增加克制的 `PROJECT 07 / EVENT VISUAL` 索引
- 暖金色背景承接原图，保持主视觉完整且不拉伸

### 02 项目背景 / Context

- 暖白底色，左侧结论型标题，右侧背景与项目档案
- 说明项目属于第 26 届深圳读书月，以阅读分享与公共表达为核心
- 项目档案包含项目类型、时间和职责
- 核心标题：阅读不只发生在书页里，也发生在一次被听见的讲述中

### 03 活动链路与传播挑战 / Journey & Challenge

- 以报名传播、评选沟通、总决赛、现场分享与留念四阶段组织活动链路
- 对应三项设计挑战：建立活动识别；平衡公共文化的正式感与参与传播的亲和力；保证横竖版、空间和数字触点的一致性
- 阶段不绑定未经证实的精确日期或赛制名称

### 04 洞察与核心概念 / Insight & Concept

- 核心句：让阅读从个人理解走向公共表达
- 解释层叠结构如何从书页逐步转译为台阶、建筑和舞台
- 解释麦克风与流动线条如何连接“读”与“讲”
- 使用官方主视觉的局部或规范图作为视觉证据

### 05 视觉识别系统 / Visual System

分为三类设计语言：

1. **上升的书页**：层叠几何承载阅读、进步与走向舞台的过程；
2. **持续的讲述**：流动等高线贯穿画面，形成声音、路径和时间感；
3. **温暖的公共文化色彩**：以 `#EED795`、`#F1CA5F`、`#D58346` 为主，`#6887BE` 作为传播层的对比色。

字体依据现有规范图呈现：张海山锐线体简、思源黑体、上首顿萧体；作品集说明文字仍优先使用苹方或思源黑体，避免缺字。

### 06 参与传播视觉 / Engagement Visual

- 使用 `38.jpg` 展示蓝黄三维阶梯、漂浮书本和麦克风
- 说明阶梯把“进步”和“走上讲述舞台”转化为更具参与感的空间隐喻
- 明确其用于招募与评选传播的亲和表达，与官方金色识别形成层级分工

### 07 版式规范与尺寸适配 / Layout Rules

- 使用 `40.jpg` 作为横版、竖版和结构网格的直接证据
- 说明 Logo 区、标题区、主图形区和信息区的层级关系
- 保持原图完整可辨，不对规则图做破坏性裁切

### 08 空间物料与导视 / Spatial Application

- 使用 `41.jpg` 展示户外灯箱、立式导视和签到物料
- 采用一张完整图与一个局部放大，说明远距离识别和近距离信息阅读的差异
- 不对现场效果作未经证明的量化评价

### 09 现场与数字触点 / Event & Digital Touchpoints

- 使用 `42.jpg` 展示活动现场、舞台分享和集体留影
- 使用 `43.jpg` 展示证件与移动端邀请物料
- 说明同一视觉语言如何从空间识别延续至人员身份和线上邀约

### 10 总结与 AI 排版指南 / Summary & Guide

- 总结项目如何把阅读、表达和公共分享组织成连续体验
- 列出画板、边距、字号、行距、图片规则和常用间距
- 保留可隐藏的尺寸标注层，方便用户在 Illustrator 中继续调整

## 网格与排版

- 画板宽度：1440 px
- 文字安全边距：72 px
- 大图安全边距：48 px
- 正文最大行宽：600–650 px
- 主标题：82–104 px
- 章节标题：48–58 px
- 引导正文：21–23 px
- 正文：15 px
- 图注：12–13 px
- 常用间距：24 / 48 / 72 / 120 px
- 中文字体优先使用苹方或思源黑体，不转曲

## 图层结构

1. `00-GUIDES`
2. `01-TYPE`
3. `02-GRAPHICS`
4. `03-IMAGES`
5. `04-ANNOTATIONS`

每个章节内对象使用 `B01-` 至 `B10-` 前缀命名。图片使用置入和裁切蒙版，保持比例，不做拉伸。标注单独成层，便于整体隐藏。

## 验收标准

- AI 文件可正常打开并包含 10 个命名画板和 5 个命名图层；
- HTML 参考与 AI 的章节、文案、尺寸和素材顺序一致；
- 至少使用官方横版 KV、传播视觉、规范图、空间物料、现场照片和数字物料六类证据；
- 项目背景、活动链路、概念推导和个人职责清晰；
- 文案不把视觉推导写成未经证明的项目事实；
- 文字无明显溢出、缺字或重叠；
- 图片不拉伸，重要信息不被错误裁切；
- 原素材和已有 PDF 不被覆盖；
- 不出现虚构数据和未经证明的活动成效。
