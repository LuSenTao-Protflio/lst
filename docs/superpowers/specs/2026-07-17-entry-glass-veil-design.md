# 入口页玻璃幕布设计

## 目标

将 `/` 改为简洁的项目导览入口：页面不再显示「卢森涛」或「个人作品集网站」标题。它以一层带磨砂质感的深橄榄绿玻璃覆盖在持续运行的光线背景上，让入口页与主作品集的深灰、酸性亮黄和玻璃语言一致。

招聘方仍可在进入主站前浏览全部项目；鼠标悬停项目名称时，名称放大并出现该项目的主视觉概览。

## 页面构成

### 背景与玻璃层

- 入口页的最底层使用与主页面 Hero 相同的深色、鼠标驱动光线效果。
- 最上层为贯穿视口的橄榄绿半透明磨砂幕布；它使用 CSS 颜色、半透明叠加、`backdrop-filter`、细微内高光和低对比阴影，不使用固定玻璃贴图。
- 橄榄绿取低饱和、偏灰的深色调，使酸性黄仍是唯一显著强调色。玻璃层允许底层的光线在鼠标移动时隐约改变明暗和纹理。
- 减少动态效果偏好下保留静态橄榄绿玻璃表面，不运行鼠标驱动光线与淡出动画。

### 顶部任务栏

- 保留入口页顶部宽任务栏的位置、信息架构和锚点目的地（WORK / INFO / CONTACT）。
- 改为半透明酸性黄玻璃，采用主页面相同的模糊、饱和度、白色内高光和暖灰阴影语汇。
- 入口栏在视觉上比主页面导航更宽；进入结束后由主页面已有的常规导航接替。无需让两个不同路由中的 DOM 元素做连续共享布局动画。

### 项目导览

- 移除入口页姓名、作品集名称、英文副标题和专业分类说明。
- 保留项目名称列表以及当前的详情页链接。
- 在精细指针设备上，悬停或键盘聚焦某个项目时：该项目名放大，其他名称降低不透明度，右侧展示项目主视觉。
- 在触摸设备上保留可点击项目名称，不显示依赖 hover 的浮动预览；版面仍保持可读。

### 进入主页面

- 底部仅保留「进入作品集」控件。
- 点击按钮、使用顶部任务栏任一目的地，或在入口页向下滚动时，都走同一进入流程。
- 进入过程仅淡出入口玻璃幕布、项目导览与入口任务栏，约 300–450ms；原先的文字逐字、光线转场界面不再出现。
- 页面导航到既有的 `/portfolio` 或对应锚点，保留当前路由目标和无障碍语义。

## 组件与数据边界

- `InteractiveCover` 仍负责入口内容、滚轮处理及进入回调；它将引入或复用 Hero 光线背景，而不是复制项目数据。
- `HoverProjectReveal` 继续唯一地从 `projects.js` 和 i18n 读取项目名称与主视觉；不改变项目排序、链接或数据结构。
- `EntryTransition` 从全屏文字/光线过场改为轻量的玻璃幕布淡出；路由仍只在动画完成时发生。
- `styles.css` 集中新增入口玻璃、光线背景、任务栏和响应式样式，维持现有暖白、深灰、酸性亮黄三色体系，并新增仅入口使用的橄榄绿表面变量。

## 可访问性与降级

- 项目名称保持真实链接，键盘 focus 获得与 hover 相同的预览/强调状态。
- 所有按钮和导航保留可见 focus 样式与当前目标地址。
- `prefers-reduced-motion` 直接导航，不渲染光线交互与淡出动画。
- 小屏不显示悬浮预览，任务栏维持现有紧凑样式，进入按钮保持在可视区底部。

## 验收

- `/` 不再显示个人姓名、作品集标题或原有的文字转场。
- 鼠标移动时，可通过橄榄绿磨砂层看到低层光线的细微变化。
- 悬停项目名可看见项目名强调和对应预览；项目点击仍进入正确详情页。
- 点击「进入作品集」和向下滚动都以短淡出进入 `/portfolio`；顶部导航按钮仍到达对应锚点。
- 减少动态效果、移动端、键盘焦点和现有主页面/项目路由不回归。
