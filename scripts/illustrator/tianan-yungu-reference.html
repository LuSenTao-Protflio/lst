01 / CONTEXT

让阅读离开单次活动，进入社区每天的生活。

天安云谷联合帆书深圳运营中心，将阅读活动放入社区日常生活，以持续 42 天的内容和交换机制连接园区居民、书店与社区伙伴。

项目需要同时组织跨月日程、不同参与方式和多方活动信息。视觉系统不仅要有公共活动的可见度，也要让参与者快速理解：什么时候发生、可以交换什么、如何加入。

03 / INSIGHT & CONCEPT

把阅读从一次文化活动，变成每天都能参与的社区交换。

打开的书本与两侧手势共同构成“交换”的动作：书页既是阅读媒介，也像被打开的社区入口。READING IS DAILY LIFE 被嵌入书页结构，让活动主张成为识别本身。

04 / VISUAL SYSTEM

让复杂活动信息，保持统一且容易区分。

黄色建立公共活动的可见度；开放书页与行动手势形成主识别；粉、蓝、绿等主题色帮助参与者区分不同交换阶段。白底黑框标签像社区公告一样自由组合。

01

开放书页

阅读符号、社区入口与交换平台，被压缩进一个可持续延展的线性图形。

02

行动手势

递出与接收的双手强调参与动作，让视觉从“观看阅读”转向“加入阅读”。

03

主题色彩

黄色稳定整体识别，粉、蓝、绿建立四阶段之间清晰而活跃的差异。

05 / FOUR EXCHANGES

四周主题连续发生

每个阶段拥有独立图形、日期和英文副标题，同时共享黄色底色、标签式标题和主图形结构。

07 / KEY VISUAL ADAPTATION

横版、竖版与独立图形

通过重新裁切书页轮廓、手势和信息标签适配媒介，而不是把同一画面机械缩放。

09 / SUMMARY & AI BUILD GUIDE

把阅读变成社区日常，也把复杂活动变成可持续的视觉系统。

设计从主视觉延展到四阶段主题、活动日历和人物传播，主要负责视觉设计与落地执行。
